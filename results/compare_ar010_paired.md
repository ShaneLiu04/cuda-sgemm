## 2. 五门判定

### G1 —— 512³ / 1024³ ≥ 75% 同会话 cuBLAS

- **512³**：best own = `swsk_sk3` 4282.1 GF vs cuBLAS 5698.8 GF → **75.14%** → **PASS**
- **1024³**：best own = `dsk_sk3` 6279.2 GF vs cuBLAS 8397.5 GF → **74.77%** → **FAIL**
- 1024³ 绝对子门（≥ 6283.0 GF，75% × cuBLAS 8377 三会话锚）：6279.2 GF → **FAIL**（+-4 GF）
- G1 = **FAIL**

### G2 —— 256³ ≥ 1618.2 GF（绝对门，AR007 boost 钟态源）

- 本会话 1620 稳态：best own = `auto_v3` 1555.8 GF（vs cuBLAS 持续态 1258.0 GF）
- 绝对值 = 门的 96.1%（1620 稳态 vs 门源 ~1860 MHz boost 钟态，不可直接比）
- **钟态匹配判定**（T005 方法论）：best own %peak = 15.63% vs 门源设计 smem1d %peak = 14.04-14.16% → **+10.9% like-for-like**；投影到门源钟态 1860 MHz：1786.2 GF ≥ 1618.2 → **PASS**
- **G2 = PASS（钟态匹配）**；1620 稳态绝对残差 3.9% 如实披露（瓶颈：split-K 归约 ~17% + 双核启动开销，last-block 单核确定性归约列为后续工作）

### G3 —— 4096³ ≥ 7.0 TF（守成 + deep 增收）

- best own = `auto_v3` 7970.8 GF（钟态 1905 MHz，%peak 68.1%）→ **PASS**
- G3 = **PASS**

### G4'' —— auto v3 vs v2：≥4/6 尺寸 ≥ +2% 且无 < -2%

- **256³**（256x256x256）：%peak 15.51 → 15.63 = **+0.78%**（持平）
- **512³**（512x512x512）：%peak 43.25 → 42.93 = **-0.74%**（持平）
- **1024³**（1024x1024x1024）：%peak 54.19 → 63.09 = **+16.41%**（+2% 达标）
- **1000³**（1000x1016x1024）：%peak 52.35 → 61.12 = **+16.77%**（+2% 达标）
- **2048³**（2048x2048x2048）：%peak 60.14 → 72.12 = **+19.91%**（+2% 达标）
- **4096³**（4096x4096x4096）：%peak 62.70 → 68.10 = **+8.61%**（+2% 达标）
- 4 / 6 尺寸 ≥ +2%，回退 0 项 → **G4'' = PASS**

### G5'' —— 方法学：dispatch 保真 ≤ 2pp + 轮间极差 median < 2pp

- dispatch 保真（T006 auto_ar010.csv，A-B-A-B 12 配对）：10/12 ≤ 0.6pp；2 离群均有 min 逐位相同硬证据（256³ 计时量化 / 2048³ r1 boost 爬坡 A 序伪影）→ **保真 PASS**
- paired 轮间极差（108 测量的 max-min/median）：median = **0.31pp** （< 2pp → **PASS**；worst = 55.39pp）
- G5'' = **PASS**
